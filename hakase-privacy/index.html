ハカセ（配信アシスタント）プライバシーポリシー

「ハカセ」は、YouTubeチャンネル運営者（ガリバー）が自分の配信のためだけに使う、個人用の配信アシスタントツールです。一般の方に提供するサービスではありません。

利用するGoogleアカウントの情報

本ツールは、YouTube Data API を通じて次の操作だけを行います。

  • 運営者自身の配信中のライブ枠を確認する
  • 運営者の指示で、そのライブチャットにコメントを投稿する

動画・コメント・チャンネル情報などのユーザーデータを収集・保存・第三者に提供することはありません。

データの保存

Googleのログイン情報（アクセストークン）は、運営者のパソコンの中にだけ保存されます。外部のサーバーには送信しません。

連携を解除するには、Googleアカウントの「サードパーティ製のアプリとサービス」で「ハカセ」のアクセスを削除してください。

YouTube利用規約

本ツールは YouTube API サービスを利用しています。
