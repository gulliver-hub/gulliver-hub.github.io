Discordのサーバー管理はBotひとつで
GDotsでできること・料金・選び方

2026年11月28日 ／ 執筆：ガリバー（Discordコミュニティマネージャー・GDots 開発者）

荒らし対策のBot、ログのBot、チケットのBot、YouTubeの通知のBot……。サーバーが大きくなるほど、Botが増えていきます。Botが増えるほど、権限の穴も、設定する画面も、止まったときの原因探しも増えます。

50以上のサーバーを運営してきた中で「これを1つにまとめたい」と思って自分で作ったのが、Discordのサーバー管理Bot「GDots（ジードッツ）」です。この記事では、GDotsでできること、料金、そして自分で設定するか、プロに任せるかの選び方を正直にまとめます。

Botを1つにまとめると、なにがよいか

GDotsでできること

管理画面はブラウザで開き、Discordのアカウントでログインするだけです。機能は大きく6つのグループに分かれています。

🛡️ 荒らし対策

AutoMod（高・中・低の型から）・ハニーポット（罠チャンネル）・連投と乗っ取りの検知・つながる守り・処罰（KICK・BAN・タイムアウト）

🩺 権限チェック

ロールとチャンネルの権限を14項目でチェックし、100点満点で採点。危ない設定はボタンひとつで直せます

🗺️ ロール・チャンネル

権限マップ（ロール×チャンネルを1枚の表で）・権限セット・一括適用・ロールの一括付与・棚卸し・バックアップ

📝 ログ・レポート

イベントログ・操作ログ・期間ごとのレポート（PDF）・メッセージの書き出し（CSV）

👋 コミュニティ

チケット・ウェルカムカード・ロールパネル・レベル・ポイント・代理投稿と予約投稿・固定メッセージ・日程調整・翻訳チャンネル

📺 SNS の通知

YouTube・X・Bluesky・Twitch・ツイキャス・note・RSS の新しい投稿や配信を Discord へ

Botを入れた直後には、いくつかの質問に答えるだけで、チャンネルやカテゴリ、ルール・お知らせ・ようこそのチャンネルまで整えてくれる「サーバーの初期設定」も使えます（使わなくてもかまいません）。

  • 必要になったら Standard・Pro へ

開発者・運営代行の方が GDots で設定するメリット

お客様の Discord サーバーを作ったり運営したりしている方にとって、GDots は「自分の道具」としても使えます。自分で Bot を作ることもできますが、作ったあとに動かし続けるのは思った以上に大変です。

  1. 型を作って、何サーバーにも同じ設定「読むだけ」「書き込める」などの権限セットを作り、たくさんのチャンネルへまとめて反映できます。お客様ごとに一から設定し直す時間を減らせます
  2. 変更は記録に残り、元に戻せるGDots で行った設定は操作ログに残ります。ロールの変更や一括付与は、あとから元に戻せます。「だれが変えたのか」でお客様ともめない
  3. 成果をレポートで見せられる期間ごとに、止めた荒らしやサーバーの動きをまとめ、PDF で渡せます（Standard プラン）。保守や運営代行の価値を、数字で伝えられる
  4. お客様のブランドで出せるBot の名前・アイコン・バナー・自己紹介を、サーバーごとに変えられます（Standard プラン）。お客様のサーバーになじむ見た目で納品できる
  5. お客様の負担を小さく始められる守る機能は永久無料なので、お客様に費用をお願いせずに入れられます。必要な機能が出てきたら、サーバーごとに Standard・Pro を選べる

GDots を紹介してくださる方向けに、GDots パートナープログラムもあります（認定制）。パートナーになると、ご自身のサーバーで Standard プランの機能をずっと無料で使えます。

保守を任せる場合（Pro プランを保証）

サーバー保守をご依頼いただいている期間は

GDots の Pro プランを保証します

通常 1サーバー月2,980円（税込）。保守のあいだ、GDots の料金を別にお支払いいただく必要はありません。

保守では、GDots を使ってガリバーがサーバーを見守ります。

  • 権限の設計と定期の点検運営メンバーの入れ替わりや Bot の追加のたびに、危ない権限が残っていないかを確認
  • 荒らし・スキャムへの対応止めるだけでなく、処罰の記録を残し、同じ手口の再発を防ぐ
  • 毎月のレポートどれだけ守れたか、サーバーがどう動いたかを数字でお伝え
  • Pro プランの機能もそのまま翻訳・AI のまとめ・X の通知も、たくさん使えます

保守の内容と料金はサーバー保守のページ、総額の目安は料金ページの依頼例をご覧ください。

よくある質問

GDots は無料で使えますか？

はい。権限チェック・AutoMod・ハニーポット・連投検知・つながる守り・処罰など、サーバーを守る機能は永久無料です。お支払い情報の登録もいりません。イベントログの全部の記録・予約投稿・レポート・翻訳などは、1サーバー月480円（税込）の Standard プランです。

ガリバーに依頼しないと使えませんか？

いいえ。GDots はどなたでもご自身で使えます。gdots.jp から Discord でログインし、Bot をサーバーに入れるだけで始められます。

いま入れている Bot は外さないといけませんか？

外さなくても使えます。同じ役目の Bot が2つあると、同じメッセージに2回反応することがあるので、GDots で置きかえられる Bot から順に外していくのがおすすめです。外す前に、その Bot に付いていた強い権限も見直してください。

自分で使い始めてから、保守に切り替えられますか？

できます。GDots の設定はそのまま引き継いで、保守を始められます。保守のあいだは Pro プランを保証します。

保守をやめたら、GDots はどうなりますか？

GDots はそのまま使えます。保守の終わりとともに Pro プランの保証も終わり、Free プランになります。続けて Standard・Pro を使いたい場合は、ご自身でご購入ください。設定は残ります。

開発者として、お客様のサーバーに GDots を入れてもいいですか？

もちろんです。お客様のサーバーを管理する権限がある方なら、管理画面から設定できます。Standard・Pro はサーバーごとのご契約です。

GDots での設定から、運営まで任せたい方へ

サーバーの構築・保守・運営代行を承っています。保守のあいだは GDots の Pro プランを保証します。「自分で GDots を使うか、任せるか迷っている」というご相談も歓迎です。ご相談・診断は無料です。
