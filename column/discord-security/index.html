Discordサーバーの乗っ取り対策｜管理者がやるべき設定と習慣

2026年11月7日 ／ 執筆：ガリバー（Discordコミュニティマネージャー）

Discordでは、管理者やモデレーターのアカウントが乗っ取られると、チャンネルの削除、メンバーの一斉追放、詐欺リンクの一斉送信などでサーバーが一瞬で壊されてしまうことがあります。

長い時間をかけて育てたコミュニティを守るために、運営者が今日からできる対策をまとめました。

  1. 自分のアカウントを守る
  2. サーバーの設定を見直す
  3. よくある乗っ取りの手口
  4. 乗っ取られたときの対処

1. 自分のアカウントを守る

二段階認証を必ずオンにする

パスワードだけでは、流出したときに防げません。Discordの「マイアカウント」から二段階認証を設定しましょう。認証アプリを使う方法が基本です。

セキュリティキーやパスキーを使う

より強く守りたい場合は、セキュリティキー（物理的な鍵）やパスキーの登録がおすすめです。偽のログイン画面にだまされても、鍵がなければログインされにくくなります。

パスワードを使い回さない

ほかのサービスと同じパスワードを使っていると、そちらから流出したときに一緒に乗っ取られます。Discord専用の、長く推測されにくいパスワードにしましょう。

2. サーバーの設定を見直す

「管理者」権限を配りすぎない

管理者権限は、サーバーのあらゆる操作ができる強い権限です。モデレーターには、メッセージの管理やメンバーのタイムアウトなど、必要な権限だけを付けましょう。

モデレーション操作に二段階認証を必須にする

サーバーの安全設定で、モデレーション操作に二段階認証を必須にできます。二段階認証をしていない運営メンバーが、強い操作をできないようにする設定です。

認証レベルとAutoModを設定する

参加したばかりのアカウントがすぐに発言できないようにする認証レベルや、怪しいリンク・スパムを自動でブロックするAutoModを設定しましょう。

Botとウェブフックを整理する

使っていないBotやウェブフックは削除し、残すBotにも必要な権限だけを与えます。強い権限のBotが乗っ取られると、運営アカウントと同じくらい危険です。

3. よくある乗っ取りの手口

  • QRコードでのログイン詐欺：「認証のためにスキャンして」とQRコードを読ませ、アカウントにログインする手口
  • 偽のプレゼント・Nitroのリンク：本物そっくりのログイン画面に誘導して、パスワードを盗む手口
  • 「誤って通報してしまった」詐欺：知り合いを装って連絡し、偽のサポート担当につないで情報を聞き出す手口
  • ファイルやツールの実行：「ゲームを試して」などと言ってファイルを実行させ、ログイン情報を盗む手口

知り合いからのメッセージでも、その人のアカウント自体が乗っ取られていることがあります。いつもと違う誘いには、別の方法で本人に確認しましょう。

4. 乗っ取られたときの対処

  1. ログインできるうちに、すぐにパスワードを変更する（すべての端末からログアウトされます）
  2. 二段階認証を設定し直し、不審なアプリ連携を解除する
  3. ほかの運営メンバーに連絡し、乗っ取られたアカウントのロールを外してもらう
  4. 監査ログで被害を確認し、メンバーへ注意を呼びかける
  5. ログインできない場合は、Discordのサポートに連絡する

いざというときに慌てないよう、運営メンバーの間で「乗っ取りが起きたら誰が何をするか」を決めておくと安心です。
